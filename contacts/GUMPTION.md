# Gumption

Intake platform for CSV / Excel / Stripe / PayPal / webhook / REST.

**Open Gumption:** [https://gumption.co](https://gumption.co)

If yours is self-hosted, set `GUMPTION_BASE_URL` in `.env` and re-run `npm run contacts` — the generated `GUMPTION.url` shortcut in `import-ipad/` and `import-android/` will point at your instance.

From Slack once Gumption is up:

```
/gumption intake
/gumption final
```
