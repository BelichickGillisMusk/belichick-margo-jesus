# Drop audio notes here for overnight Grok

Name files to match the walkthrough step:

```

02-stripe.m4a
03-invoices.m4a
04-tests.m4a
05-vin-date.m4a
06-week-calls.m4a

```

Also drop a `.txt` next to any audio with the same stem if you already transcribed it (`01-open-gumption.txt`). Grok reads `.txt` first, then transcribes leftover audio.

The walkthrough page can download notes for you — tap **Save note** on a step, then AirDrop/move the file into this folder before you sleep.
